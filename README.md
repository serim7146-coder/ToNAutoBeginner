# ToNAutoBeginner
**VRChat ワールド「Terrors of Nowhere」（ToN）を複数窓で回すための支援ツール**

自動自爆・自動 Begin を中心に、続行ラウンドの管理、アイテムの取り直し、統計などをまとめて行います。

## ダウンロード
* [インストーラー（おすすめ）](https://github.com/serim7146-coder/ToNAutoBeginner/releases/latest/download/ToNAutoBeginner-Setup.exe)
* [exe 単体](https://github.com/serim7146-coder/ToNAutoBeginner/releases/latest/download/ToNAutoBeginner.exe)

### インストール・アップデート・アンインストール
* インストーラーは管理者権限なしで入れられます。入れる場所は選べます（既定は `%LOCALAPPDATA%\Programs\ToNAutoBeginner`。Program Files など管理者権限が要る場所は選べません）。スタートメニューから起動できます。
* アップデートはツールが自動で行います。設定や統計は残ります。
* exe 単体で使っている場合は、起動したときに自動でインストーラー版へ移行します（設定・統計はそのまま。移行後に前の exe は消えます）。入れる場所は前の exe があったフォルダです（入れられない場所なら `%LOCALAPPDATA%\Programs\ToNAutoBeginner`）。
* アンインストールは Windows の「設定 → アプリ」から行います。設定・統計・ログ・画像（`%APPDATA%\ToNAutoBeginner`）と展開先（`%LOCALAPPDATA%\ToNAutoBeginner`）も消えます。

## はじめに（使う前の準備）
* **VRChat はデスクトップ版**で使います。
* **OSC を有効**にしてください（移動・Begin・速度検知などに使います）。ツールから VRChat を起動すると、窓ごとに OSC のポートを割り当てます（窓1 = 送信 9000／受信 9001、窓2 = 9010／9011、…）。
* **アバター**
  * 自動 Begin を使う窓では、ふつうの身長のアバターを使ってください。身長が低すぎると、Begin の台の文字がほぼ真横からしか見えず、押せないことがあります（ツールは視点を上下に動かしません）。
  * 速度検知・アイテム自動取得は、アバターの `VelocityMagnitude`・`Grounded` のパラメータを使います（無いアバターでは動きません）。
* **続行リスト**を用意してください（[使い方](#使い方)の 1）。

## 使い方
1. **続行リストを用意する**（どちらか一方でよい）
   * ToN ListTool（2.13 以降）を起動して周回を組む。起動中で、参加者・待機の誰かが続行リストを持っている間は、その主催リストを自動で使います（取れなくなったら .tnl に戻ります）。
   * 「① 続行リスト(.tnl)」で「参照…」から .tnl ファイルを選ぶ。.tnl は [ToN ListTool](https://booth.pm/ja/items/7722619) の「欲しいリスト作成・編集」→ 続行を選ぶ →「エクスポート(.tnl)」で出せます。
2. 「② 窓数・ログ設定」の「窓数」を選ぶ
3. 使う窓を順に選ぶ（または「🚀 VRChatを起動」でツールから起動する）
4. 「📄 最新ログを自動割り当て」を押す
5. 使いたい機能にチェックを入れる
6. 「▶ マクロ開始」を押す（同じボタンが「■ 停止」に変わり、もう一度押すと止まります）

ボタンは「▶ マクロ開始」「📋 オーバーレイ」「統計」「⌨ キーバインド」「報告」の順に並んでいます。

## インスタンスによる違い
| インスタンス | できること |
|---|---|
| **プライベート**（フレンド・フレンド+・インバイト・インバイト+） | すべての機能（移動・クリック・Begin・チェイス・アイテム取得・Run のリスポーンなど） |
| **干し芋・焼き芋**（グループ） | グループのルールでの自動自爆（[詳しい仕様](#自動自爆)）。判定・音声 |
| **そのほか**（パブリック・ほかのグループ・Emerald City など） | 判定・音声・統計のみ。**移動・クリック・OSC の操作はしません** |

* 窓を前面にする・窓を切り替える・窓の位置を戻す、はどのインスタンスでも行います。

## 機能

### 自爆・続行・Begin
* **自動自爆**：続行リストに無いラウンドで自爆します。
  * ラウンドごとの「自爆する」「全続行する」の指定（プライベートのみ）。Fog・Ghost・8 Pages を選ぶと、それぞれの (Alternate) にも効きます。
  * DTM/Waldo 続行（3クラ解放まで。窓ごとの「3クラ解放後も続行」で解放後も）
* **自動 Begin**：ラウンドが終わったら Begin を押します。背面の窓は、カーソルを一瞬だけ窓の上に置いて押します（前面を奪いません）。
* **完全放置モード**：自爆できるようになったら自爆します（プライベートのみ）。

### 全窓フリーズ
次のときに、ほかの窓の操作を止めて、その窓を優先します。
* 続行ラウンド（その窓を前面にします）
* アイテムロストの装備待ち
* 指定したラウンドへの突入（「フリーズ」の枠の「ラウンド突入」）
* 速度検知（同じ枠の「速度検知」で 8 Pages／Punished）

### アイテムを落とす・窓位置リセット（どちらも既定 ON）
チェック「アイテムを落とす」「窓位置リセット」で、それぞれ切れます。
* **アイテムを落とす**（どのラウンドの後でも）：どのラウンドでも、終わったら（RoundOver の後に 1 回）その窓へ OSC で「落とす」を送ります（プライベートで OSC が使える窓のみ）。続行ラウンドは、続行が終わったとき（窓を戻す前）に 1 回です。Run のリスポーン・Begin 前の移動・アイテム自動取得とは重ならないよう、その前に送ります。
* **窓位置リセット**（続行ラウンドの後に窓を元の位置に戻す）：続行ラウンドの始まりの窓の位置を覚え、終わったら戻します。フルスクリーンなら前面にして Alt+Enter で窓に戻し、最大化なら元の大きさに戻してから、位置だけ戻します（大きさは変えません）。

### 速度検知
* Begin を押した直後の移動の速さで、次のラウンドが 8 Pages／Punished かを先読みします。
* 速さは VRChat から OSC で受け取ります。まず **OSCQuery**（ほかのアプリと同時に使える受け方）で 15 秒待ち、届かなかった窓だけ、その窓の受信ポート（9001 など）を開きます。受信ポートもほかのアプリ（ToN Utils など）が使っていたら、その窓では速度検知をしません（画面のログに、ポートを使っているアプリの名前が出ます）。

### アイテム自動取得（プライベートのみ）
* ロストしたアイテムを、店で装備し直します（Enkephalin・Survival・Event の店。Others の店のアイテムは取りません）。
* 窓を前面にして、店の画面全体が見えるよう視点を合わせ、Tab を押したままカーソルを店のボタン・Equip へ置いて押します。押すボタンが画面左下の HUD に重なるときは、店の画面を真ん中へ寄せてから押します。
* 「アイテム取得→Begin」モード：Begin の前に取りに行かず、ロストしたら知らせて止まります。

### Utilsの判断に従う（既定 OFF）
チェック「Utilsの判断に従う」を入れると、ToN Utils が続行・自爆を判断する窓では、その判断に従います。
* Utils で自爆を許可した窓だけで効きます。Utils が自爆すればスキップ（このツールは押しません）、何もしなければ続行（続行フリーズ・アナウンスなど、このツールの続行と同じ）。許可していない窓は、このツールが今までどおり判定・自爆します。
* テラーが決まってから 3 秒、Utils の判断を待ちます。Fog など隠れるラウンドは、テラーが明かされてから待ちます（霧即時判定などで先に分かっても待ちます）。
* Utils が動いていない・その窓のセーブの記録が見つからない・Utils を起動してからその窓の判断をまだ見ていない、のどれかなら、その窓はこのツールが判定します（画面のログに理由が出ます）。
* Utils のログ（`%APPDATA%\ton-syncskip\ton-utils.log`）と、窓の対応のために `save-history.sqlite` の `logs` 表（source・started だけ）を読み取り専用で読みます。

### Runリスポーン（既定 ON。チェック「Runリスポーン」で切れます。プライベートで OSC が使える窓のみ）
* Run のラウンドに入ったら、リスポーンして（窓を前面にして Esc のメニューのリスポーンを押す）、後ろへ下がって階段（Begin）の方を向きます。
* 向いた後に画面を撮って階段の上の目印を探し、ずれていれば少しずつ直します（直して悪くなったら一つ戻して止めます）。
* ほかの窓がフリーズ中（続行ラウンドなど）は、前面にしないで待ちます。

### チェイス（既定 ON。「⌨ キーバインド」の画面の「チェイスを使う」で切れます）
* ラウンド中に F1（時計回り）／F2（反時計回り）を押すと、前面の窓がぐるぐる回ります。もう一度押すと止まります（プライベートのみ）。
* 切ると F1・F2 を拾わなくなり、ほかのキーに使えます。

### VRChat の起動
* 窓ごとのプロファイル（`--profile=`）で起動し、OSC のポートを割り当てます。
* ToN への自動 Join、入室後の選択画面の自動突破（プライベートのみ）、続けて Begin まで押す。
  * **セーブコードの読み込み**（「続けてBeginまで押す」が ON のとき）：Begin へ動く前に、クリップボードのセーブコード（SaveManager がコピーしたもの）を Save/Load のコード欄に貼って読み込みます（Tab を押したままクリック → 入力欄に貼る → Enter）。全窓に同じコードを貼ります。VRChat のログの「Loaded Data Successfully」で確かめ、読み込めなくても Begin は押します。セーブコードはツールのログに出しません。
  * **Guidance Plush**（チェック。既定 OFF。「続けてBeginまで押す」が ON のときだけ）：Begin が受け付けられたら（Verified）、店へ行って Guidance Plush を装備します（Event Shop の一覧を下へ送り、Have Plush を選んで Equip）。店へ行く移動にマクロの受信を使うので、マクロが動いている窓だけで行います。止まっている窓では「取りに行きません」と出して飛ばします。

### 窓を整列（「② 窓数・ログ設定」の「🚀 VRChatを起動」の行）
* **窓を整列**：割り当てた窓（窓1〜）を、窓1 があるモニターの作業領域（タスクバーを除く）に等分して、大きさもそろえて並べます。前面は奪いません。
  * 1 窓は全体、2 窓は横に 2 つ、3〜8 窓は 2 段（8 窓は 4×2、6 窓は 3×2）。3・5・7 窓は、窓1 が左の列で縦長になります。
  * 最大化・最小化の窓は、前面を奪わずに元に戻してから並べます。フルスクリーンの窓は、Alt+Enter で窓に戻してから並べます（その間だけ、その窓が前面になります）。戻せなかった窓は並べません（画面のログに出ます）。
  * 見えている枠どうしがぴったり並ぶように、Windows の窓の見えない縁を差し引きます。
* **配置を覚える**：今の各窓の位置と大きさを、窓の番号ごとに覚えます（最大化の窓は元の大きさ。フルスクリーン・最小化の窓は覚えません）。次からの「窓を整列」は、覚えた窓をその位置へ戻し、覚えていない窓だけを等分して並べます。覚えた位置が画面の外（モニターを外したなど）なら、等分の方で並べます。
* **✕**：覚えた配置を消して、等分の並べ方に戻します。
* 窓を大きくすると、その窓は VRAM（GPU のメモリ）を多く使います。重くなったら窓を小さくしてください（[困ったとき](#困ったとき) の VRAM の行も）。

### そのほか
* **霧即時判定**（チェック「霧即時判定」）：公開前にテラーを特定します（フレンド・インバイト+・インバイトのみ）。
* **窓の音量**：窓の状態（続行・フリーズ・そのほか）で VRChat の窓ごとの音量を変えます。
* **OBS 自動録画**：続行ラウンドを録画します。
* **外部ツールの起動ボタン**（ToN ListTool など）
* **音声アナウンス**：アイテムロストラウンドの後（Punished・8 Pages・Run）、続行ラウンド、霧ラウンド、Intermission 突入（Begin が押せるようになった時）、Foxy 出現、速度検知でのラウンド、指定したラウンドへの突入、主催リストが取れなくなったとき。
* **統計**：ラウンドを集めて、テラーの出やすさなどを表示します（[統計](#統計)）。
* **不具合の報告**：ログ・設定・撮影を添えて開発者へ送ります（[不具合の報告](#不具合の報告)）。

## キー操作
キーは「⌨ キーバインド」の画面で変えられます。どのキーも「解除」でき、解除したキーは押しても何もしません（停止のキーを解除するときは確認が出ます。解除すると、止めるのは「■ 停止」のボタンだけになります）。今のキーはメインの画面に 1 行で出ます。

| キー | 既定 | 働き |
|---|---|---|
| マクロ開始 | 未設定 | 止まっているときに「▶ マクロ開始」を押したのと同じ。開始だけで、動いているときに押しても何もしません |
| 停止 | P（変更可） | マクロを止めます。長押しは要りません |
| 自爆キャンセル | ^ | そのラウンドは全窓とも自爆しません |
| チェイス | F1（時計回り）・F2（反時計回り） | 前面の窓が回り続けます（[機能](#機能) のチェイス） |

## 詳しい仕様

### 自動自爆
* Run は自爆しません。Run の窓が選ばれることもありません。
* 8 Pages はテラーを正確に判定できません。
* Bloodbath EX は、ラウンド開始では Bloodbath と出るため、テラーが出た時点で 3 体が同じなら Bloodbath EX と判定します。
* 干し芋・焼き芋のインスタンスでは、次のルールで自爆します（自動自爆が ON のとき）。
  * Classic（Variant を除く）・Bloodbath・Classic.exe・Randomizer は自爆します。
  * Moon は 2 回目から自爆します。焼き芋では Mystic Moon と Solstice を 1 回目から自爆します。
  * 8 Pages・Run・Bloodbath EX は自爆しません。
  * Fog は、干し芋では自爆しません。焼き芋ではオルタネイト枠だけを続行リストで判定し、ほかは自爆します。
  * Sabotage は参加者の続行の希望で判定します。
* 完全放置モード
  * Run は自爆しません。8 Pages はテラーが出てから自爆します。
  * 「DTM/Waldo続行」が ON で 3 クラ解放前（「3クラ解放後も続行」が ON なら解放後も）なら、DTM と（アイテムを持っているときの）Waldo は続行します。
  * 「アイテム自動取得」が ON なら、完全放置モードでも Guidance Plush をロストしたときだけ取りに行きます。

### 3 クラ解放
* 「DTM/Waldo続行」は、特殊ラウンドを見るか、3 勝を「マクロ開始」の状態で迎えると、内部で自動的に解除されます。
  * 窓ごとの「3クラ解放後も続行」を ON にすると、解除の後も DTM/Waldo を続行します。
  * DTM/Waldo の続行は Cracked などの特殊ラウンドでも行います。テラーが複数体出るラウンド（Double Trouble・Bloodbath・Midnight）だけは続行しません（Bloodbath EX は続行します）。
* Guidance Plush を持っているときだけ Waldo を続行します（Guidance Plush の番号は item.json から名前で引きます）。

### 統計
* 統計画面は、データベースから差分だけを手元（`%APPDATA%\ToNAutoBeginner\rounds.sqlite`）へ取り込み、手元で集計します。
* 確率密度関数に二項分布を仮定しています。
* 「テラー出現回数」の「上側 p 値」は、出た回数以上になる確率です。
* 「判定」は棄却域 α で決まります：α = 0.05 ⇒ 出やすい、α = 0.025 ⇒ かなり出やすい、α = 0.01 ⇒ テーブル！

### 不具合の報告
* 「何が起きましたか」に書いて送ると、選んだものを zip にまとめて開発者へ送ります。
* 窓は、窓ごとのチェックか「すべて」で複数選べます（何も選ばなければ「窓なし」）。選んだ窓それぞれの VRChat のログ（末尾）と撮影が入ります。全体が 9.5MB に収まるよう、ログは窓の数で分け合います。
* 撮影（Begin が見つからなかったとき・Run の向きが合わなかったとき）や VRChat のログには、ほかのプレイヤーの名前が写る・入ることがあります。

## 送るデータ・置くファイル
* **データベース（統計）に送るもの**："ラウンド開始の時刻、ラウンドタイプ、テラー ID（3 体まで）、マップ ID、transformed_uid、インスタンスの番号"
  * transformed_uid は、データベースを軽くするために VRChat の uid を任意の番号（int2）に変えたものです。
  * インスタンスの番号は、インスタンス ID から作ったハッシュ値です。同じインスタンスの同じラウンドを 1 行にまとめるために使います。ソロ（自分以外がいないと分かっている）のときは送りません。
  * Moon・Run・Special はテラーなしで送ります。
  * 霧即時判定で分かったテラーは、即時判定が使えないインスタンスでも、画面に出さずにデータベースへ送ります。
* **手元に置くもの**（`%APPDATA%\ToNAutoBeginner`）：設定、統計（rounds.sqlite）、debug.log（詳しい動作の記録）、撮影（Begin が見つからなかったとき・Run の向きが合わなかったとき（run_face、最新 20 枚））

## 困ったとき
| 症状 | 見るところ・対処 |
|---|---|
| 速度検知が効かない／横移動だけする | 画面のログに「速さを受け取れません（… は ○○ が使っています）」が出ていないか。受信ポートをほかのアプリが使っていて、OSCQuery でも届いていません。そのアプリより先にツールの監視を始めるか、その窓で VRChat の OSC を一度切って入れ直すと、OSCQuery で届くことがあります |
| Begin が押されない | アバターの身長（[はじめに](#はじめに使う前の準備)）。窓が最小化されていないか |
| 1 窓をフルスクリーンにすると全部の窓が重くなる | VRAM（GPU のメモリ）が足りずに溢れています。フルスクリーンの解像度を下げる、VRChat の画質（アンチエイリアスなど）を下げる、OBS など VRAM を使うアプリを閉じる、フルスクリーンにせず大きめの窓にする |
| Run でリスポーンしない | VRChat の FPS が低いとメニューのクリックを取りこぼすことがあります（そのときは何もせずに終わります）。debug.log の「Run:」の行で理由が分かります |
| よく分からない動きをした | 「不具合の報告」から、その窓（関係しそうなら複数・すべて）を選んで送ってください |
