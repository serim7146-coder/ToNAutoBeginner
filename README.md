# ToNAutoBeginner
**VRChat ワールド「Terrors of Nowhere」（ToN）を複数窓で回すための支援ツール**

自動自爆・自動 Begin を中心に、続行ラウンドの管理、アイテムの取り直し、統計などをまとめて行います。

## ダウンロード
* [インストーラー（おすすめ）](https://github.com/serim7146-coder/ToNAutoBeginner/releases/latest/download/ToNAutoBeginner-Setup.exe)
* [exe 単体](https://github.com/serim7146-coder/ToNAutoBeginner/releases/latest/download/ToNAutoBeginner.exe)

### インストール・アップデート・アンインストール
* インストーラーは管理者権限なしで入れられます。入れる場所は選べます（既定は `%LOCALAPPDATA%\Programs\ToNAutoBeginner`。Program Files など管理者権限が要る場所は選べません）。スタートメニューから起動できます。
* アップデートはツールが自動で行います。設定や統計は残ります。
* exe 単体で使っている場合は、起動したときに自動でインストーラー版へ移行します（設定・統計はそのまま。移行後に前の exe は消えます）。入れる場所は前の exe があったフォルダです（入れられない場所なら `%LOCALAPPDATA%\Programs\ToNAutoBeginner`）。
* アンインストールは Windows の「設定 → アプリ」から行います。設定・統計・ログ・画像（`%APPDATA%\ToNAutoBeginner`）と展開先（`%LOCALAPPDATA%\ToNAutoBeginner`）も消えます。

## はじめに（使う前の準備）
* **VRChat はデスクトップ版**で使います。
* **OSC を有効**にしてください（移動・Begin・速度検知などに使います）。ツールから VRChat を起動すると、窓ごとに OSC のポートを割り当てます（窓1 = 送信 9000／受信 9001、窓2 = 9010／9011、…）。
* **アバター**
  * 自動 Begin を使う窓では、ふつうの身長のアバターを使ってください。身長が低すぎると、Begin の台の文字がほぼ真横からしか見えず、押せないことがあります（視点の高さを合わせるのは VRChat が前面の窓だけで、背面の窓では上下に動かしません）。
  * 速度検知・アイテム自動取得は、アバターの `VelocityMagnitude`・`Grounded` のパラメータを使います（無いアバターでは動きません）。
* **続行リスト**を用意してください（[使い方](#使い方)の 1）。

## 使い方
1. **続行リストを用意する**（どちらか一方でよい）
   * ToN ListTool（2.13 以降）を起動して周回を組む。起動中で、参加者・待機の誰かが続行リストを持っている間は、その主催リストを自動で使います（取れなくなったら、ツールの中の続行リストに戻ります）。
   * ツールの中の続行リストを使う。「① 続行表」の「続行表」ボタンの画面の下の「.tnl を続行リストへ読み込む」で .tnl ファイルを選ぶと、ツールの続行リストがその中身になります（ツールの中で直した分は置き換わるので、確認が出ます）。.tnl は [ToN ListTool](https://booth.pm/ja/items/7722619) の「欲しいリスト作成・編集」→ 続行を選ぶ →「エクスポート(.tnl)」で出せます。続行リストは「続行表」の画面でも直せます（[続行リスト](#続行リストツールの中)）。
2. 「② 窓数・ログ設定」の「窓数」を選ぶ
3. 使う窓を順に選ぶ（または「🚀 VRChatを起動」でツールから起動する）
4. 「📄 最新ログを自動割り当て」を押す
5. 使いたい機能にチェックを入れる
6. 「▶ マクロ開始」を押す（同じボタンが「■ 停止」に変わり、もう一度押すと止まります）

ボタンは「▶ マクロ開始」「📋 オーバーレイ」「統計」「⌨ キーバインド」「報告」の順に並んでいます。

## インスタンスによる違い
| インスタンス | できること |
|---|---|
| **プライベート**（フレンド・フレンド+・インバイト・インバイト+） | すべての機能（移動・クリック・Begin・チェイス・アイテム取得・Run のリスポーンなど） |
| **Seer's Apostle**（グループオンリーのインスタンス） | プライベートとまったく同じ（霧即時判定も）。グループ+・グループ公開では「そのほか」と同じで、マクロも霧即時判定もしません |
| **干し芋・焼き芋**（グループ） | グループのルールでの自動自爆（[詳しい仕様](#自動自爆)）。判定・音声 |
| **そのほか**（パブリック・ほかのグループ・Emerald City など） | 判定・音声・統計のみ。**移動・クリック・OSC の操作はしません** |

* 窓を前面にする・窓を切り替える・窓の位置を戻す、はどのインスタンスでも行います。

## 機能

### 自爆・続行・Begin
* **自動自爆**：続行リストに無いラウンドで自爆します。
  * ラウンドごとの「全自爆」「全続行」の指定（プライベートのみ）。Fog・Ghost・8 Pages を選ぶと、それぞれの (Alternate) にも効きます。
    * 全続行のラウンドでも続行リストは見ます。続行リストで続行になれば、普通の続行ラウンドと同じ（アナウンス・ほかの窓のフリーズ・音量「続行」・録画・窓位置リセット）、ならなければ自爆しないだけです。
    * Run を選ぶと、Run でリスポーンせずに走ります。
  * DTM/Waldo 続行（3クラ解放まで。窓ごとの「3クラ後もDTM/Waldo続行」で解放後も）
* **自動 Begin**：ラウンドが終わったら Begin を押します。背面の窓は、カーソルを一瞬だけ窓の上に置いて押します（前面を奪いません）。横に動いて位置を合わせるときは 1 歩 0.1 秒まで（行き過ぎないように）。VRChat が前面の窓では、BEGIN が照準より上や下にあるとき、マウスで視点の高さも合わせてから押します（合わせた視点は戻しません）。Begin が見えないときは後ろや前へ動いて探し、台座などの壁に当たったら後ろへ下がって探します。BEGIN が見つからない・押しても通らずあきらめた窓は、30 秒後と、それから 3 分おきに、リスポーンして Begin の前からやり直します。
* **完全放置モード**：自爆できるようになったら自爆します（プライベートのみ）。

### 続行リスト（ツールの中）
続行リストは、ツールの中に自分のものを持っています（主催リストを使っていないときの、判定の元のリストです）。
* 保存先は `%APPDATA%\ToNAutoBeginner\continue_list.json` です。初めて起動したとき（このファイルが無いとき）だけ、前に選んでいた .tnl から作ります。それ以後は .tnl を読みません（.tnl のファイルは書き換えません。ToN ListTool のフォルダにも書きません）。
* 中身の番号は、ツール独自のテラー番号です（[テラーの番号](#テラーの番号)）。前の版（ToN ListTool の番号）で作った continue_list.json は、初めて起動したときに独自の番号へ直して保存し直します。直す前のファイルは `continue_list.json.listtool.bak` として残します（すでに .bak があれば上書きしません。.bak が作れなかったときは、ファイルを直しません）。
* メイン画面の「① 続行表」に、`Nラウンド / M件 続行対象` が出ます（主催リストを使っているときは `[主催リスト] …`）。
* 「続行表」ボタンの画面の下に、続行リストの 2 つのボタンがあります（ファイルを選ぶ画面はその画面の上に出ます）。
  * 「.tnl を続行リストへ読み込む」：選んだ .tnl でツールの続行リストを置き換えます（確認が出ます）。
  * 「続行リストを .tnl に書き出す」：ツールの続行リストを .tnl に書き出します（保存先を聞きます）。ToN ListTool で読み込めます。
* 「続行表」の画面で、上の切り替え（続行リスト・続行無効・デフォ続行。開いたときは続行リスト）に「続行リスト」があります（枠の色は青）。続行無効・デフォ続行と同じように、アイコンを押す・全選択・全解除・名前で検索ができます。プリセットは無いので、プリセットの欄は隠れます。変えるとすぐ全窓の判定に効き、保存は 0.3 秒まとめて 1 回です。続行リストを選んでいるとき、続行無効・デフォ続行に入っているものは細い枠で見えます。
* **生存したら自動で外れます**：窓がラウンドで生存すると、そのラウンドの種類の続行リストから、そのラウンドのテラー（判定に使った番号）が外れます（例：Classic で Huggy を生存 → Classic の Huggy だけ外れます）。
  * Mystic Moon・Blood Moon・Twilight・Solstice・Special・Cold Night のラウンドは、ツールの「Special/Moon」から外れます（この 6 つは 1 つのキーです）。テラーが複数体のラウンドは、リストに入っているものがすべて外れます。
  * 外れたらすぐ保存し、全窓へ反映し、メイン画面の件数を更新します。ログに `[続行リスト] 生存したので外しました: Huggy / Classic` と出ます。手で戻したものは、また生存するまで残ります。
  * 外れないとき：主催リストを使っている間・干し芋/焼き芋・リストに入っていないとき・テラーが分からないとき（Fog でテラー不明のまま、など）。
  * 続行無効・デフォ続行は触りません（デフォ続行に入っていれば、外れた後も続行します）。

### テラーの番号
ツールの中のテラーの番号は、ToN ListTool の番号ではなく、ツール独自の番号です（`assets/data/terror_ids.json`）。

| 範囲 | 中身 |
|---|---|
| 0〜999 | Classic（ゲームのログの番号そのまま） |
| 1000〜 | Alternate（1000 ＋ ログの番号。Alternate の枠に来た 36 以上の番号も 1000 番台） |
| 2000〜 | Unbound（2000 ＋ ログの番号） |
| 3000〜 | 8 Pages（3000 ＋ 8 Pages のログの番号。Classic の同じテラーとは別の番号） |
| 4000〜 | 固定の表（4000 HHI・4001 Atrached・4002 Wild Yet Bloodthirsty Creature・4003〜4006 Moon の 4 体・4007 Rift Monsters・4008 Meatball Man・4009 The Gigabytes・4010 Neo Pilot・4011 Evil Purple Foxy・4012 Glorbo・4013 Self Inserts (Bloodthirsty)） |

* ログの番号を独自の番号に直すのは、ログを読む入口の 1 か所だけです。そこから先（判定・続行リスト・続行表・統計・DB）は、すべて独自の番号です。ToN ListTool の番号を使うのは、.tnl・.tnnl・主催リストとやり取りするときだけです。
* ログの表示は番号ではなく名前です（`Terror set: Huggy / Classic`）。名前が分からない番号は `#番号` と出ます。表に無い 8 Pages のページは `#3070` のようになり、debug.log に 1 回だけ残ります。
* `assets/data/terrors.json`（手で直すファイル）の番号も、この独自の番号です。8 Pages の行の `id` は、3000 を足さない**ページ番号そのもの**で、`list_id` はありません（ツールの中の番号は 3000 ＋ `id`）。番号を足すときは後ろに足し、一度決めた番号は動かしません。
* ToN ListTool の「Special/Moon」「Mystic Moon」「Blood Moon」は、ツールでは「Special/Moon」の 1 つにまとめています。.tnl を書き出すときは、ツールの「Special/Moon」から ToN ListTool の 3 つのキーを作り直します。
* 前の版のファイル（continue_list.json・continue_table.json・rounds.sqlite）は、初めて起動したときに独自の番号へ直し、直す前のものを `.listtool.bak`（rounds.sqlite は `rounds.sqlite.listtool.bak`）として残します。すでに .bak があるときは上書きしません。.bak が作れなかったときは、そのファイルを直しません。

### 続行表（メイン画面の「① 続行表」）
今の続行リスト（ツールの中の続行リスト・ToN ListTool の主催リスト）の上に、2 つの表を重ねます。
* **続行無効**：チェックしたテラーは、続行リストにあっても続行しません。
* **デフォ続行**：チェックしたテラーは、続行リストになくても（続行無効にあっても）続行します。主催リストで生存済みとして消えたテラーも続行できます。
* 重ねた後の続行リスト ＝（今の続行リスト − 続行無効）＋ デフォ続行。
* **プリセット**：続行無効とデフォ続行は、それぞれ名前を付けたプリセットをいくつでも作れます（初めは「既定」の 1 つ。前のバージョンで作った表は、そのまま「既定」になります）。「続行表」ボタンの画面の上の段、「続行無効／デフォ続行」を選ぶと切り替えの横に、その表のプリセットのドロップダウンと「新規」「複製」「名前変更」「削除」があります。アイコンを押す・全選択・全解除・ファイルの読み込みは、選んでいるプリセットに効きます。同じ名前や「なし」「窓のまま」は付けられません。最後の 1 つは削除できません。削除したプリセットを使っていた窓は「既定」になります（「既定」が無ければ先頭）。
* **窓ごとの選び**：メイン画面の各窓の設定の行に「続行無効:」「デフォ続行:」のドロップダウンがあり、その窓が使うプリセットを選びます（保存して、すぐ判定に効きます）。「なし」を選ぶと、その窓ではその表を重ねません（窓ごとの ON/OFF です）。まだ選んでいない窓は「既定」を使います。
* 「続行表」ボタンの画面で、左のラウンドの一覧から選び、テラーのアイコンを押して選びます。見た目は ToN ListTool に寄せています（名前は出さず、マウスを乗せると名前が出ます。選んでいないアイコンは暗く、今の表に入っているものは明るく太い枠＝赤は続行無効・緑はデフォ続行、もう片方の表に入っているものは少し暗く細い枠）。1 行 12 個で、マスの間隔は縦横とも 46px です。Alternate は 11・9・7・5・3・1 の逆三角です。
* **選べないマス**：そのラウンドに出ないテラー（Ghost の一部、Fog の 1 体、Punished・Midnight・Bloodbath の一部、8 Pages に出ないものなど）も、格子の形を崩さないために位置はそのままで、暗い絵・枠なしの「選べないマス」として出ます。押しても何も起きず、全選択・全解除の対象にもなりません。マウスを乗せると「（このラウンドには出ません）」と出ます。続行リストにも、そのラウンドの枠としては持ちません。
* 4000 番台のテラー（HHI・Atrached・Bloodthirsty・Gigabytes・Neo Pilot・Evil Purple Foxy・Glorbo・Self Inserts (Bloodthirsty) など）は、格子の下の「バリアントの段」に並びます（そのラウンドの枠にあるものだけ）。8 Pages のタブは、8 Pages のテラーを ToN ListTool の位置に置きます（位置が決まっていないものは別のまとまりに出ます）。
* 一覧の「Special/Moon」は、Mystic Moon・Blood Moon・Twilight・Solstice・Special・Cold Night を 1 つにまとめたものです。ツールのキーも 1 つで、押す・全選択・全解除はその 1 つに効きます。ToN ListTool の Mystic Moon・Blood Moon のキーは、.tnl の読み込み・書き出しのときだけ使います（[テラーの番号](#テラーの番号)）。
* 「全選択」「全解除」は、今のラウンドで見えているアイコン全部（バリアントの段も）を、今のプリセットに入れる・外します。名前で検索して絞っているときは、合っているものだけです。
* 名前で検索できます（合わないものは暗いままです）。押すと、判定にはその場で効き、保存は 0.3 秒まとめて 1 回です（画面を閉じるときも残りを保存します）。
* **Self Inserts (Bloodthirsty)**：Unbound の Self Inserts に Bloodthirsty が付いたときは、ToN ListTool のリストでは指定できないので、いつも続行します。その窓の続行無効のプリセットの Unbound に Self Inserts (Bloodthirsty) を入れると、その窓ではいつも続行はやめて、普通の続行リストの判定（Self Inserts がリストにあるか）にします。デフォ続行に入れても今までと同じです。干し芋・焼き芋ではこの表を使わず、今までどおりいつも続行します。
* **アイテムで切り替え**：「続行表」ボタンの画面の下の「アイテムで切り替え」の欄で、窓が今持っているアイテムによって使うプリセットを切り替えます。決まりは全窓共通で、1 行が 1 つの決まりです（アイテム・続行無効のプリセット・デフォ続行のプリセット・「↑」「↓」で入れ替え・「×」で削除。「決まりを足す」で増やします）。アイテムは「持っていない」か、item.json のアイテム（店ごとにまとまっています）です。プリセットは「窓のまま」（その種類は窓の選んだプリセットを使う）・「なし」（その表を重ねない）・プリセット名から選びます。窓が持っているアイテムに当てはまる最初の決まり（上が先）を、判定のたびに見ます。当てはまる決まりが無ければ、窓の選んだプリセットだけです。同じアイテムの決まりが 2 つあると上だけが使われ、下は薄い文字で出ます。持っているアイテムは今までと同じ追い方で、ロストした後は「持っていない」になります（Self Inserts (Bloodthirsty)（4013）も、決まりで選ばれたプリセットで見ます。干し芋・焼き芋では使いません）。プリセットの名前を変えると決まりの中の名前も変わり、削除すると、それを指していた決まりは「窓のまま」になります。決まりのプリセットが窓の選択と変わったときは、判定のログの行の最後に `〔Guidance Plush の決まり〕`（持っていないときは `〔持っていない の決まり〕`）が付きます（結果が変わらなくても付きます）。
* ToN ListTool のファイルを読み込めます：続行リスト（.tnl）→ デフォ続行、強制スキップ（.tnnl）→ 続行無効（選んでいるプリセットの今の中身は置き換わります）。読み込むとき、ToN ListTool の番号をツールの独自の番号に直します（ToN ListTool の「Special/Moon」「Mystic Moon」「Blood Moon」の中身は、ツールの「Special/Moon」へ振り分けます。そのラウンドに出ないテラーは取り込まず、debug.log に残します）。前の版で作った continue_table.json も、初めて起動したときに独自の番号へ直して保存し直します（直す前のファイルは `continue_table.json.listtool.bak`）。
* 干し芋・焼き芋では使いません。3 クラ済みの完全放置モード・全続行・全自爆・自爆するラウンドの指定など、続行リスト以外の決まりは今までどおりです（その決まりで自爆するなら、デフォ続行にあっても自爆します）。
* 重ねた表で結果が変わったときは、判定のログの後ろに `（デフォ続行）` か `（続行無効）` が付きます。
* 保存先は `%APPDATA%\ToNAutoBeginner\continue_table.json` です。

### 全窓フリーズ
次のときに、ほかの窓の操作を止めて、その窓を優先します。
* 続行ラウンド（その窓を前面にします）
* アイテムロストの装備待ち
* 指定したラウンドへの突入（「フリーズ」の枠の「ラウンド突入」。Sabotage murder（自分がマーダー）・Sabotage star・Cracked・Double Trouble も選べます）
* 速度検知（同じ枠の「速度検知」で 8 Pages／Punished）

### アイテムを落とす・窓位置リセット（どちらも既定 ON）
チェック「アイテムを落とす」「窓位置リセット」で、それぞれ切れます。
* **アイテムを落とす**：そのラウンドで死んだとき・生き残ったときに、1 回だけその窓へ OSC で「落とす」を送ります（プライベートで OSC が使える窓のみ）。続行ラウンドも同じです（続行が終わったときには落としません）。死んだ・生き残ったが出ないラウンド（Run のリスポーンなど）では落としません。落としてもアイテムロストとは数えません。
* **窓位置リセット**（続行ラウンドの後に窓を元の位置に戻す）：続行ラウンドの始まりの窓の位置を覚え、終わったら戻します。フルスクリーンなら前面にして Alt+Enter で窓に戻し、最大化なら元の大きさに戻してから、位置だけ戻します（大きさは変えません）。

### 速度検知
* Begin を押した直後の移動の速さで、次のラウンドが 8 Pages／Punished かを先読みします。入室時に Guidance Plush を取れず、やり直しが控えている窓では、やり直しの移動とぶつかるので横移動はしません（速さの受信は変わりません）。
* 速さは VRChat から OSC で受け取ります。まず **OSCQuery**（ほかのアプリと同時に使える受け方）で 15 秒待ち、届かなかった窓だけ、その窓の受信ポート（9001 など）を開きます。受信ポートもほかのアプリ（ToN Utils など）が使っていたら、その窓では速度検知をしません（画面のログに、ポートを使っているアプリの名前が出ます）。

### アイテム自動取得（プライベートのみ）
* ロストしたアイテムを、店で装備し直します（Enkephalin・Survival・Event の店。Others の店のアイテムは取りません）。
* 窓を前面にして、店の画面全体が見えるよう視点を合わせ、Tab を押したままカーソルを店のボタン・Equip へ置いて押します。押すボタンが画面左下の HUD に重なるときは、店の画面を真ん中へ寄せてから押します。
* 「アイテム取得→Begin」モード：Begin の前に取りに行かず、ロストしたら知らせて止まります。ロストした回は、ツールは Begin 前の移動も Begin も行いません。装備と Begin はご自身で行ってください（受理されると他の窓のフリーズが解けます）。

### Utilsの判断に従う（既定 OFF）
チェック「Utilsの判断に従う」を入れると、ToN Utils が続行・自爆を判断する窓では、その判断に従います。
* Utils で自爆を許可した窓だけで効きます。Utils が自爆すればスキップ（このツールは押しません）、何もしなければ続行（続行フリーズ・アナウンスなど、このツールの続行と同じ）。許可していない窓は、このツールが今までどおり判定・自爆します。
* テラーが決まってから 3 秒、Utils の判断を待ちます。Fog など隠れるラウンドは、テラーが明かされてから待ちます（霧即時判定などで先に分かっても待ちます）。
* Utils が動いていない・その窓のセーブの記録が見つからない・Utils を起動してからその窓の判断をまだ見ていない、のどれかなら、その窓はこのツールが判定します（画面のログに理由が出ます）。
* Utils のログ（`%APPDATA%\ton-syncskip\ton-utils.log`）と、窓の対応のために `save-history.sqlite` の `logs` 表（source・started だけ）を読み取り専用で読みます。

### Runリスポーン（既定 ON。チェック「Runリスポーン」で切れます。プライベートで OSC が使える窓のみ）
* Run のラウンドに入ったら、リスポーンして（窓を前面にして Esc のメニューのリスポーンを押す）、後ろへ下がって階段（Begin）の方を向きます。
* 向いた後に画面を撮って、特徴点で玉座を探し（FOV や解像度が違っても見つかる）、ずれていれば少しずつ直します（直して悪くなったら一つ戻して止めます）。
* 前後の位置は直しません。後ろへは、動き出してから数えて下がります（重くて動き出しが遅れても同じだけ下がります。動き出さなければ押し直します）。
* ほかの窓がフリーズ中（続行ラウンドなど）は、前面にしないで待ちます。
* 全続行で Run を選んだ窓はリスポーンせず、そのまま走ります（他の窓は止めません。止めたいなら突入フリーズで Run を選びます）。

### チェイス（既定 ON。「⌨ キーバインド」の画面の「チェイスを使う」で切れます）
* ラウンド中に F1（時計回り）／F2（反時計回り）を押すと、前面の窓がぐるぐる回ります。もう一度押すと止まります（プライベートのみ）。
* 切ると F1・F2 を拾わなくなり、ほかのキーに使えます。

### VRChat の起動
* 窓ごとのプロファイル（`--profile=`）で起動し、OSC のポートを割り当てます。
* ToN への自動 Join、入室後の選択画面の自動突破（プライベートのみ）、続けて Begin まで押す。
  * 「入室後の選択画面を自動突破」と「自動でBeginを押す」が両方 ON なら、入室操作の前にマクロを自動で開始します（止まっているときだけ）。
  * **セーブコードの読み込み**（「自動でBeginを押す」が ON のとき）：Begin へ動く前に、クリップボードのセーブコード（SaveManager がコピーしたもの）を Save/Load のコード欄に貼って読み込みます（Tab を押したままクリック → 入力欄に貼る → Enter）。全窓に同じコードを貼ります。VRChat のログの「Loaded Data Successfully」で確かめ、読み込めなくても Begin は押します。セーブコードはツールのログに出しません。
  * **Guidance Plushを自動取得**（チェック。「自動でBeginを押す」が ON のときだけ）：Begin が受け付けられたら（Verified）、店へ行って Guidance Plush を装備します（Event Shop の一覧を下へ送り、Have Plush を選んで Equip）。店へ行く移動にマクロの受信を使うので、マクロが動いている窓だけで行います。止まっている窓では「取りに行きません」と出して飛ばします。店の操作は、Begin が受理されてから 5 秒以内に順番が回ってきたときだけ行います。間に合わない回は見送って、次のラウンドの後にまた行きます（やり直しの回数は減りません）。

### 窓を整列（「② 窓数・ログ設定」の「🚀 VRChatを起動」の行）
* **窓を整列**：割り当てた窓（窓1〜）を、窓1 があるモニターの作業領域（タスクバーを除く）に等分して、大きさもそろえて並べます。前面は奪いません。
  * 1 窓は全体、2 窓は横に 2 つ、3〜8 窓は 2 段（8 窓は 4×2、6 窓は 3×2）。3・5・7 窓は、窓1 が左の列で縦長になります。
  * 最大化・最小化の窓は、前面を奪わずに元に戻してから並べます。フルスクリーンの窓は、Alt+Enter で窓に戻してから並べます（その間だけ、その窓が前面になります）。戻せなかった窓は並べません（画面のログに出ます）。
  * 見えている枠どうしがぴったり並ぶように、Windows の窓の見えない縁を差し引きます。
* **配置を覚える**：今の各窓の位置と大きさを、窓の番号ごとに覚えます（最大化の窓は元の大きさ。フルスクリーン・最小化の窓は覚えません）。次からの「窓を整列」は、覚えた窓をその位置へ戻し、覚えていない窓だけを等分して並べます。覚えた位置が画面の外（モニターを外したなど）なら、等分の方で並べます。
* **✕**：覚えた配置を消して、等分の並べ方に戻します。
* 窓を大きくすると、その窓は VRAM（GPU のメモリ）を多く使います。重くなったら窓を小さくしてください（[困ったとき](#困ったとき) の VRAM の行も）。

### そのほか
* **霧即時判定**（チェック「霧即時判定」）：公開前にテラーを特定します（フレンド・インバイト+・インバイトのみ）。
* **窓の音量**：窓の状態（続行・全続行・フリーズ・そのほか）で VRChat の窓ごとの音量を変えます。「全続行」は、ラウンド指定の全続行の窓と、ラウンド突入のフリーズで止めた窓です（続行 ＞ 全続行 ＞ フリーズ ＞ そのほか）。続行・全続行・ラウンド突入のフリーズの窓の音量は、死んでも生き残っても、そのラウンドの RoundOver まで変えません。
* **AFK 回避**：ツールが自爆しないラウンドで、生きたまま 70 秒動いていなければ、フレンド＋以下の窓は少しだけ前へ動き、それ以外の窓は警告音（AFK）を鳴らします。DTM/Waldo・Glorbo の AFK 解除が動いている窓では何もしません。速さを一度も受け取れていない窓では、鳴らさず・動かしません。
* **OBS 自動録画**：続行ラウンドを録画します。
* **外部ツールの起動ボタン**（ToN ListTool など）：ボタンの「起動中」の表示は、ツールを起動してから最大 10 秒ほど遅れて切り替わります。
* **音声アナウンス**：アイテムロストラウンドの後（Punished・8 Pages・Run）、続行ラウンド、霧ラウンド、Intermission 突入（Begin が押せるようになった時）、Foxy 出現、速度検知でのラウンド、指定したラウンドへの突入、主催リストが取れなくなったとき。
  * 「③ サウンド設定」の「アナウンス」で、声ごとに音量（0〜100%）を変えられます。実際の音量は「ツールの音量」（全体）と掛け合わせたものです（全体 80%・アイテムロスト 50% なら 40%）。各行の ▶ で、今の音量で 1 回鳴らして確かめられます（マクロが止まっていても鳴ります）。
  * 各行の頭のチェックで、声ごとに鳴らす・鳴らさないを切り替えられます（保存します）。外していても ▶ では鳴らせます。ファイル欄はファイル名だけを出し、フルパスはマウスを乗せると出ます。
* **統計**：ラウンドを集めて、テラーの出やすさなどを表示します（[統計](#統計)）。
* **不具合の報告**：ログ・設定・撮影を添えて開発者へ送ります（[不具合の報告](#不具合の報告)）。

## キー操作
キーは「⌨ キーバインド」の画面で変えられます。どのキーも「解除」でき、解除したキーは押しても何もしません（停止のキーを解除するときは確認が出ます。解除すると、止めるのは「■ 停止」のボタンだけになります）。今のキーはメインの画面に 1 行で出ます。

| キー | 既定 | 働き |
|---|---|---|
| マクロ開始 | 未設定 | 止まっているときに「▶ マクロ開始」を押したのと同じ。開始だけで、動いているときに押しても何もしません |
| 停止 | P（変更可） | マクロを止めます。長押しは要りません |
| 自爆キャンセル | ^ | そのラウンドは全窓とも自爆しません |
| チェイス | F1（時計回り）・F2（反時計回り） | 前面の窓が回り続けます（[機能](#機能) のチェイス） |

## 詳しい仕様

### 自動自爆
* Run は自爆しません。Run の窓が選ばれることもありません。
* Bloodbath EX は、ラウンド開始では Bloodbath と出るため、テラーが出た時点で 3 体が同じなら Bloodbath EX と判定します。
* 干し芋・焼き芋のインスタンスでは、次のルールで自爆します（自動自爆が ON のとき）。
  * Classic（Variant を除く）・Bloodbath・Classic.exe・Randomizer は自爆します。
  * Moon は 2 回目から自爆します。焼き芋では Mystic Moon と Solstice を 1 回目から自爆します。
  * 8 Pages・Run・Bloodbath EX は自爆しません。
  * Fog は、干し芋では自爆しません。焼き芋ではオルタネイト枠だけを続行リストで判定し、ほかは自爆します。
  * Sabotage は参加者の続行の希望で判定します。
  * 自爆しないラウンド（8 Pages・Bloodbath EX・Moon・干し芋の Fog・Run）でも、その窓の続行リストにそのテラーがあれば、普通の続行ラウンドと同じ（アナウンス・ほかの窓のフリーズ・音量「続行」・録画）になります。テラーが分からないとき（Run・テラーがまだ出ていない Fog など）や、リストに無いときは、今までどおり自爆しないだけです。
* 完全放置モード
  * Run は自爆しません。8 Pages はテラーが出てから自爆します。
  * 「DTM/Waldo続行」が ON で 3 クラ解放前（「3クラ後もDTM/Waldo続行」が ON なら解放後も）なら、DTM と（アイテムを持っているときの）Waldo は続行します。
  * Glorbo、Bloodbath EX の 3 体 DTM、Guidance Plush を持っているときの Bloodbath EX の 3 体 Waldo は、3 クラの状態や設定に関係なく続行します（他の窓は止めます。アナウンス・録画はしません）。
  * 「アイテム自動取得」が ON なら、完全放置モードでも Guidance Plush をロストしたときだけ取りに行きます。

### 3 クラ解放
* 「DTM/Waldo続行」は、特殊ラウンドを見るか、3 勝を「マクロ開始」の状態で迎えると、内部で自動的に解除されます。
  * 窓ごとの「3クラ後もDTM/Waldo続行」を ON にすると、解除の後も DTM/Waldo を続行します。
  * DTM/Waldo の続行は Cracked などの特殊ラウンドでも行います。テラーが複数体出るラウンド（Double Trouble・Bloodbath・Midnight）だけは続行しません（Bloodbath EX は続行します）。
* Guidance Plush を持っているときだけ Waldo を続行します（Guidance Plush の番号は item.json から名前で引きます）。

### 統計
* 統計画面は、データベースから差分だけを手元（`%APPDATA%\ToNAutoBeginner\rounds.sqlite`）へ取り込み、手元で集計します。取り込み元は、新しいテーブル（`ToNRounds_v2`。独自の番号・人数あり）と、前のテーブル（`ToNRounds`。ToN ListTool の番号を独自の番号に直して取り込み。人数は不明）の 2 つで、それぞれ取り込んだ位置を別に覚えます。前のテーブルを読むのは移行の間だけです。
* 8 Pages のラウンドは、手元には 3000 番台のまま貯め、集計のときに同じテラーの数へ足します（8 Pages の Huggy は Classic の Huggy と同じ 1 体として数えます）。8 Pages にしか出ないテラー（Baldi など）は、足す先が無いので 3000 番台のまま数えます。ページ番号が表に無い行は、どのテラーにも足せず集計に出ません。
* ラウンド開始時のインスタンスの人数（自分を含む）も貯めます。人数が分からなかったときは空です。
* 確率密度関数に二項分布を仮定しています。
* 「テラー出現回数」の「上側 p 値」は、出た回数以上になる確率です。
* 「判定」は棄却域 α で決まります：α = 0.05 ⇒ 出やすい、α = 0.025 ⇒ かなり出やすい、α = 0.001 ⇒ テーブル！

### 不具合の報告
* 「何が起きましたか」に書いて送ると、選んだものを zip にまとめて開発者へ送ります。
* 窓は、窓ごとのチェックか「すべて」で複数選べます（何も選ばなければ「窓なし」）。選んだ窓それぞれの VRChat のログ（末尾）と撮影が入ります。全体が 9.5MB に収まるよう、ログは窓の数で分け合います。
* 撮影（Begin が見つからなかったとき・Run の向きが合わなかったとき）や VRChat のログには、ほかのプレイヤーの名前が写る・入ることがあります。

## 送るデータ・置くファイル
* **データベース（統計）に送るもの**："ラウンド開始の時刻、ラウンドタイプ、テラー ID（3 体まで）、マップ ID、transformed_uid、インスタンスの番号、人数"
  * テラー ID はツール独自の番号です（[テラーの番号](#テラーの番号)）。送り先は `rpc/register_round_v2`（テーブルは `ToNRounds_v2`）で、人数は `p_players` です。前の版が使っていた `rpc/register_round`（ToN ListTool の番号）は使いません。
  * 人数は、ラウンド開始時のインスタンスにいた人数（自分を含む）です。分からないときは空（null）で送ります。
  * transformed_uid は、データベースを軽くするために VRChat の uid を任意の番号（int2）に変えたものです。
  * インスタンスの番号は、インスタンス ID から作ったハッシュ値です。同じインスタンスの同じラウンドを 1 行にまとめるために使います。ソロ（自分以外がいないと分かっている）のときは送りません。
  * Moon・Run・Special はテラーなしで送ります。
  * 霧即時判定で分かったテラーは、即時判定が使えないインスタンスでも、画面に出さずにデータベースへ送ります。
* **手元に置くもの**（`%APPDATA%\ToNAutoBeginner`）：設定、続行リスト（continue_list.json）、続行表（continue_table.json）、統計（rounds.sqlite）、前の版から移したときの `*.listtool.bak`、debug.log（詳しい動作の記録）、霧即時判定の名前ごとの答え合わせ（fog_object_names.json）、撮影（Begin が見つからなかったとき・Run の向きが合わなかったとき（run_face、最新 20 枚））

## 困ったとき
| 症状 | 見るところ・対処 |
|---|---|
| 速度検知が効かない／横移動だけする | 画面のログに「速さを受け取れません（… は ○○ が使っています）」が出ていないか。受信ポートをほかのアプリが使っていて、OSCQuery でも届いていません。そのアプリより先にツールの監視を始めるか、その窓で VRChat の OSC を一度切って入れ直すと、OSCQuery で届くことがあります |
| Begin が押されない | アバターの身長（[はじめに](#はじめに使う前の準備)）。窓が最小化されていないか |
| 1 窓をフルスクリーンにすると全部の窓が重くなる | VRAM（GPU のメモリ）が足りずに溢れています。フルスクリーンの解像度を下げる、VRChat の画質（アンチエイリアスなど）を下げる、OBS など VRAM を使うアプリを閉じる、フルスクリーンにせず大きめの窓にする |
| Run でリスポーンしない | VRChat の FPS が低いとメニューのクリックを取りこぼすことがあります（そのときは何もせずに終わります）。debug.log の「Run:」の行で理由が分かります |
| よく分からない動きをした | 「不具合の報告」から、その窓（関係しそうなら複数・すべて）を選んで送ってください |
