## インストール・アンインストール
* インストーラーは管理者権限なしで入れます。入れる場所は選べます（既定は `%LOCALAPPDATA%\Programs\ToNAutoBeginner`。Program Files など管理者権限が要る場所は選べません）。スタートメニューから起動できます。
* アップデートは今までどおりツールが自動で行います。設定や統計は残ります。
* アンインストールは Windows の「設定 → アプリ」から行います。設定・統計・ログ・画像（`%APPDATA%\ToNAutoBeginner`）と展開先（`%LOCALAPPDATA%\ToNAutoBeginner`）も消えます。
* exe 単体で使っている場合は、起動したときに自動でインストーラー版へ移行します（設定・統計はそのまま。移行後に前の exe は消えます）。入れる場所は、前の exe があったフォルダです（Program Files など入れられない場所なら `%LOCALAPPDATA%\Programs\ToNAutoBeginner`）。

# ToNAutoBeginner
**VRChatワールド「Terrors of Nowhere」向けの支援ツール**

# 主な機能
* 複数窓を制御し、自動自爆や自動Beginを行う
  * 続行リストは ToN ListTool の主催リスト（起動中で、続行リストを持つ人がいるとき）か、.tnl ファイル
  * ラウンドごとの自爆・続行の指定（プライベートインスタンスのみ）
  * 干し芋・焼き芋のグループインスタンスのルール
  * DTM/Waldo 続行（3クラ解放まで。窓ごとの設定で解放後も）
  * 完全放置モード
* 全窓フリーズ（続行ラウンド・アイテムロストの装備待ち・指定したラウンドへの突入・速度検知）
* 速度検知（Begin を押した直後の移動速度で 8 Pages / Punished を先読み）
* 霧の即時判定（公開前にテラーを特定。Friends・Invite+・Invite のみ）
* アイテム自動取得（ロストしたアイテムを店で装備し直す）／アイテム取得→Begin モード
* VRChat の起動（窓ごとのプロファイル・ToN への自動 Join・入室後の選択画面の自動突破）
* 外部ツール（ToN ListTool など）の起動ボタン
* 続行ラウンドの OBS 自動録画
* Run のラウンドに入ったら、リスポーンして階段（Begin）の方を向く（既定 ON。チェックで切れます。プライベートインスタンスで、OSC が使える窓のみ）
  * 窓を前面にして Esc でメニューを開き、リスポーンのボタンを押してから、後ろへ下がって正面を向きます。ほかの窓がフリーズ中（続行ラウンドなど）は前面にしないで待ちます。
* 続行ラウンドの後にアイテムを落とす・窓を元の位置に戻す（どちらも既定 ON。チェックで切れます）
  * アイテムを落とす: 続行ラウンドが終わったら、その窓へ OSC で「落とす」を送ります（プライベートインスタンスで、OSC が使える窓のみ）。
  * 窓を戻す: 続行ラウンドの始まりの窓の位置を覚え、終わったら戻します。フルスクリーンなら前面にして Alt+Enter で窓に戻し、最大化なら元の大きさに戻してから、位置だけ戻します（大きさは変えません）。始まりにフルスクリーン・最小化だった窓は覚えません（最大化なら元の位置を覚えます）。
* 窓の状態で VRChat の窓ごとの音量を変える
* ラウンド収集+統計データ
* 不具合の報告（ログ・設定を添えて開発者へ送る）
* 音声アナウンス
  * アイテムロストラウンド後(Punished, 8 Pages, Run)
  * 続行ラウンド
  * 霧ラウンド
  * intermission突入(Beginが押せるようになった時)
  * Foxy出現
  * 速度検知でのラウンド
  * 指定したラウンドへの突入
  * 主催リストが取れなくなったとき

# 使用方法
1. 続行リストを用意する。どちらか一方でよい。
    * ToN ListTool（2.13 以降）を起動して周回を組む。起動中で、参加者・待機の誰かが続行リストを持っている間は、その主催リストを自動で使います（取れなくなったら .tnl に戻ります）。
    * 「①続行リスト(.tnl)」にて、「参照」から.tnlファイルを選択。.tnlファイルは以下の手順で出力できます。
        1. [ToN ListTool](https://booth.pm/ja/items/7722619)を起動
        2. 「欲しいリスト作成・編集」を選択
        3. 続行を選ぶ
        4. 「エクスポート(.tnl)」を選択して出力
2. 「②窓数・ログ設定」内の「窓数」を選択
3. 使用する窓を直接、順に選択
4. 「最新ログを自動割り当て」を選択
5. 使用したい機能を選択
6. 「マクロ開始」を押す

# 詳細な仕様
## アバターの身長について
* 自動 Begin を使う窓では、ふつうの身長のアバターを使ってください。
  * 身長が低すぎると、Begin の台の BEGIN の文字がほぼ真横からしか見えず、照準も台の側面に当たるため、Begin を押せないことがあります（ツールは視点を上下に動かしません）。
## 自動自爆について
* Runは自爆を行いません。Runラウンドの窓が選択されることもありません。
* ~~April Foolイベント中に配布された当ツールはSanicをFoxyに置換しています。ex.) Foxy生存済みで、Sanic未生存の際は、Foxyで判定され、生存済みと判定されます。~~
* 8 Pagesはテラーを正確に判定できません。
* Bloodbath EX はラウンド開始では Bloodbath と出るため、テラーが出た時点で3体が同じテラーなら Bloodbath EX と判定します。
* 干し芋・焼き芋のインスタンスでは、次のルールで自爆します（自動自爆が ON のとき）。
  * Classic（Variant を除く）・Bloodbath・Classic.exe・Randomizer は自爆します。
  * Moon は2回目から自爆します。焼き芋では Mystic Moon と Solstice を1回目から自爆します。
  * 8 Pages・Run・Bloodbath EX は自爆しません。
  * Fog は、干し芋では自爆しません。焼き芋ではオルタネイト枠だけを続行リストで判定し、ほかは自爆します。
  * Sabotage は参加者の続行の希望で判定します。
* 「完全放置モード」は、自爆できるようになった時に自爆します（プライベートインスタンスのみ）。
  * Run は自爆しません。8 Pages はテラーが出てから自爆します。
  * 「DTM/Waldo続行」が ON で3クラ解放前（「3クラ解放後も続行」が ON なら解放後も）なら、DTM と（アイテムを持っているときの）Waldo は続行します。
  * 「アイテム自動取得」が ON なら、完全放置モードでも Guidance Plush をロストしたときだけ取りに行きます。
* 自爆キャンセルのキー（既定は ^）を押すと、そのラウンドは全窓とも自爆しません。
## 3クラ解放について
* 「DTM/Waldo続行」は、特殊ラウンドを見るか、3勝を「マクロ開始」の状態で迎えることで内部的に自動で解除されます。
  * 窓ごとの「3クラ解放後も続行」を ON にすると、解除の後も DTM/Waldo を続行します。
  * DTM/Waldo の続行は Cracked などの特殊ラウンドでも行います。テラーが複数体出るラウンド（Double Trouble・Bloodbath・Midnight）だけは続行しません（Bloodbath EX は続行します）。
* Guidance Plushを所持している時のみWaldoを続行します。
  * Guidance Plush の番号は item.json から名前で引きます。
## 統計について
* データベースに送るデータは"ラウンド開始の時刻, ラウンドタイプ, テラーID（3体まで）, マップID, transformed_uid, インスタンスの番号"です。
  * transformed_uid は、データベースの軽量化の観点から VRChat uid を任意の int2 に変えたものです。
  * インスタンスの番号は、インスタンスIDから作ったハッシュ値です。同じインスタンスの同じラウンドを1行にまとめるために使います。ソロ（自分以外がいないと分かっている）のときは送りません。
  * Moon・Run・Special はテラーなしで送ります。
  * 霧の即時判定で分かったテラーは、即時判定が使えないインスタンスでも、画面に出さずにデータベースへ送ります。
* 統計画面は、データベースから差分だけを手元（%APPDATA%\ToNAutoBeginner\rounds.sqlite）へ取り込み、手元で集計します。
* 内部的には、確率密度関数に二項分布を仮定しています。
* 「テラー出現回数」の「上側p値」は、出た回数以上の確率密度関数の面積(確率)です。
* 「判定」は、a(棄却域)によって判定されます。
  * a = 0.05 ⇒ 出やすい
  * a = 0.025 ⇒ かなり出やすい
  * a = 0.01 ⇒ テーブル！
## その他機能
* 緊急停止：P（変更可）を押せばマクロを停止します。長押しは要りません。
* マクロ開始のキー：設定すると、そのキーで「マクロ開始」を押したのと同じになります（既定は未設定）。
* チェイス：ラウンド中に F1（時計回り）／F2（反時計回り）を押すと、前面の窓がぐるぐる回ります。もう一度押すと止まります。
